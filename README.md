# Toopchi

A local party game: guess who started in iconic football matches.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## How to play

1. Add 2–10 player names and pick a match (or random).
2. Take turns guessing starters on the pitch — **+100** for each correct guess.
3. Game ends when all 22 starters are found, or after 3 stale rounds.
4. Highest score wins.

## Matches included

World Cup, Champions League, and Premier League classics — 8 matches in `src/data/matches.json`.

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- React Router
